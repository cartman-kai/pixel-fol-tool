# Pixel Fol Tool (Python 版)

这是 Pixel Fol Tool 的最基础版本，使用 Python 编写，适合跨平台脚本自动化和快速实验。

## 环境要求

- Python 3.6+

## 使用方法

### 1. 解包文件 (Unpack)

```bash
python fol_tool.py unpack mb.fol -o extracted_folder
```

### 2. 打包文件 (Pack)

```bash
python fol_tool.py pack extracted_folder -o new_data.fol
```

### 3. 查看帮助

```bash
python fol_tool.py -h
```
